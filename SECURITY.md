# Security policy

This project is alpha software. Security fixes target the latest default-branch revision; older snapshots are unsupported.

Do not open a public issue containing an exploit, credential, personal data, or production log. Use GitHub private vulnerability reporting when available. Otherwise contact the maintainer privately through the contact method on the maintainer's GitHub profile.

Include the affected revision, configuration, reproduction steps, impact, and mitigation. Remove secrets and personal data from logs.

WP Rescue reduces accidental exposure through network separation and conservative defaults. It does not replace a host firewall, access control, patch management, monitoring, backups, restore tests, or incident response.
